---------------------------------------------------------------------------------
  AI Tutor Project - Full Manual Setup Commands (Windows Command Prompt)
---------------------------------------------------------------------------------

**Prerequisites:**
  - Git:           (https://git-scm.com/download/win)
  - Python 3.10+:  (https://www.python.org/downloads/windows/)
                   (Ensure "Add Python to PATH" is checked during installation)
  - Node.js (LTS): (https://nodejs.org/en/download/)
                   (npm is included. Ensure "Add to PATH" is checked)

---------------------------------------------------------------------------------
  PART 1: CLONE THE PROJECT
---------------------------------------------------------------------------------

 1. Open Command Prompt.

 2. Navigate to where you want to store the project (e.g., your user's Documents folder).
cd %USERPROFILE%\Documents
 Or: mkdir MyProjects && cd MyProjects

3. Clone the repository (replace <repository_url> with the actual GitHub URL).
git clone <repository_url> ai-tutor-project
 (This clones it into a folder named 'ai-tutor-project')

 4. Navigate into the cloned project's root directory.
cd AiTutor

---------------------------------------------------------------------------------
  PART 2: BACKEND SETUP (Django with SQLite)
---------------------------------------------------------------------------------

5. Navigate into the backend directory.
cd backend

6. Create a Python virtual environment.
python -m venv venv

7. Activate the virtual environment.
.\venv\Scripts\activate

8. Install Python dependencies.
pip install -r requirements.txt

9. Create the .env file for backend environment variables.
Copy the example file.
copy .env.example .env

10. **MANUAL STEP:** Open 'backend\.env' in a text editor (like Notepad or VS Code).
    Fill in your actual values for:
      - DJANGO_SECRET_KEY="your_very_strong_random_secret_key_here"
       - GEMINI_API_KEY="your_google_gemini_api_key_here"
    Save and close the file. You MUST do this before proceeding.
notepad .env
 (Or use your preferred editor)

 11. Create the SQLite database and apply migrations.
python manage.py makemigrations api
python manage.py migrate

12. (Optional) Create a Django superuser for accessing the admin panel.
python manage.py createsuperuser
REM (Follow the prompts to set username, email, and password)

 13. (Optional but Recommended) Create media subdirectories if not automatically handled by settings.py
IF NOT EXIST "media" mkdir "media"
IF NOT EXIST "media\uploaded_resources" mkdir "media\uploaded_resources"
IF NOT EXIST "media\temp_chat_uploads" mkdir "media\temp_chat_uploads"

Backend setup is mostly complete. Keep this terminal open (with venv activated)
to run the backend server later.

---------------------------------------------------------------------------------
  PART 3: FRONTEND SETUP (React)
---------------------------------------------------------------------------------

 14. Open a NEW, SEPARATE Command Prompt.

 15. Navigate into the project's root directory (if not already there from Part 1).
cd path\to\your\ai-tutor-project
 Example: cd %USERPROFILE%\Documents\ai-tutor-project

 16. Navigate into the frontend directory.
cd frontend

 17. Install Node.js dependencies.
npm install

Frontend setup is complete. Keep this terminal open to run the frontend server.

---------------------------------------------------------------------------------
  PART 4: RUNNING THE APPLICATION
---------------------------------------------------------------------------------

18. In the FIRST Command Prompt (for the Backend):
    - Ensure you are in the 'backend' directory.
     - Ensure the virtual environment is still active (you should see '(venv)' at the start of the prompt).
      If not, reactivate: .\venv\Scripts\activate
    - Start the Django development server using Uvicorn:
uvicorn tutor_project.asgi:application --reload --port 8001

   You should see output indicating the server is running on http://127.0.0.1:8001/

19. In the SECOND Command Prompt (for the Frontend):
     - Ensure you are in the 'frontend' directory.
     - Start the React development server:
    npm run dev

     You should see output indicating the server is running, usually on http://localhost:3001/
     The terminal will often say: "Local: http://localhost:3001/"

20. Open your web browser and navigate to the frontend URL (e.g., http://localhost:3001).

---------------------------------------------------------------------------------
  STOPPING THE APPLICATION
---------------------------------------------------------------------------------

- In each Command Prompt window (backend and frontend), press CTRL+C.
- Confirm if asked (usually by pressing 'Y' then Enter).
- To deactivate the Python virtual environment in the backend terminal (optional, happens on close):
   (Run this while in the 'backend' directory with venv active)
  deactivate
